Check all pages for global design guideline:
1. Sources should always be put in "Source" tags with hover-over that match the existing design and should not stand alone as texts (no Articles, Annexes, Paragraphs, items,...).
2. Result banners should always show result, explanation, and sources, with sources in "Source" tags and not in the text. The text should be complete sentences.
3. Make sure typography hierarchy, visual spacing, and styling patterns,what should/shouldn't be bold, how the sentences are structured, etc align across pages.
5. Make punctuation marks are correctly spaced from ensuing texts.
6. User-facing texts should not use underscore in place of blank space. For example, display "Product Manufacturer" instead of "Product_Manufacturer"
